# Extension Icons

Place your extension icons in this folder with the following sizes:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon32.png` - 32x32 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Guidelines

- Use PNG format with transparency
- Keep design simple and recognizable at small sizes
- Use consistent colors across all sizes
- Consider using a food-related icon (e.g., fork and knife, chef hat, food delivery)

## Temporary Placeholder

For development, you can use placeholder icons. The extension will work without icons, but Chrome will show a default placeholder.

## Recommended Tools

- [Figma](https://www.figma.com/) - Design icons
- [GIMP](https://www.gimp.org/) - Free image editor
- [Photoshop](https://www.adobe.com/products/photoshop.html) - Professional image editor
- [Icon Generator](https://www.favicon-generator.org/) - Generate multiple sizes from one image
