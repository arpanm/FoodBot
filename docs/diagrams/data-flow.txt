4. AUTHENTICATION FLOW
======================

Client                Gateway API             Redis              PostgreSQL
  |                       |                     |                     |
  |--POST /auth/login---->|                     |                     |
  |  {email, password}    |--findUser-----------|-------------------->|
  |                       |<--user--------------|---------------------|
  |                       |                     |                     |
  |                       |--verifyPassword---->|                     |
  |                       |  (bcrypt compare)   |                     |
  |                       |                     |                     |
  |                       |--signJWT----------->|                     |
  |                       |  (15min access,     |                     |
  |                       |   7d refresh)       |                     |
  |<--{accessToken,-------|                     |                     |
  |    refreshToken}      |                     |                     |
  |                       |                     |                     |
  |--GET /orders--------->|                     |                     |
  |  Auth: Bearer {jwt}   |--validateJWT------->|                     |
  |                       |  (check blacklist)  |                     |
  |                       |<--valid-------------|                     |
  |                       |--queryOrders--------|-------------------->|
  |<--{orders}------------|                     |                     |
  |                       |                     |                     |
  |--POST /auth/logout--->|                     |                     |
  |  Auth: Bearer {jwt}   |--blacklistToken---->|                     |
  |                       |  (add to Redis set) |                     |
  |<--{message: ok}-------|                     |                     |
